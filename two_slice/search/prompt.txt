You are designing a PRB-allocation controller for a shared radio pool with 2 network slices: slice 0 is a PRIORITY (emergency) slice with an SLA target of 80 Mbps that it MUST meet; slices 1..1 are BEST-EFFORT (saturated) slices whose throughput we want as high as possible.

Write a pure Python function EXACTLY named `controller` with signature:
    def controller(history, state, sla, predictors):

Objects:
